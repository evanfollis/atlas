# Lineage: crypto-agent-dp-lab

[crypto-agent-dp-lab](https://github.com/evanfollis/crypto-agent-dp-lab) is an
archived November 2025 predecessor in the same systematic-research portfolio.
It implemented a substantive JAX/Equinox prototype for end-to-end
differentiable programming and a neuro-symbolic Φ-layer.

Its central comparative hypothesis was never tested: the planned Phase 2 study
has no committed results or artifacts. Historical “complete” labels describe
implementation milestones, not validated performance.

Atlas did not absorb that code. The predecessor optimizes a coupled pipeline
end-to-end on a heavy JAX/GPU stack; Atlas uses a smaller CPU stack and a
falsification-first process with immutable pre-registration, walk-forward OOS
evidence, explicit decisions, and a promotion gate. Importing the prototype
would blur both the scientific and dependency boundaries.

The predecessor is preserved as engineering lineage. No source asset was
copied: its repository has no open-source license, and this migration did not
grant reuse rights.
