# Atlas agent-charter evaluation dimensions

Cases cover the highest-risk intersections of:

- artifact ownership: contributor-owned vs runner-owned vs generated;
- epistemic state: hypothesis, correlation, OOS/live evidence, promotion;
- operational state: code landed, service started, outcome verified;
- containment: credential scope, bounded root exception, runtime migration;
- change shape: targeted seam vs mechanical flattening; and
- governance: ordinary documentation vs behavior-shaping instructions.

The set is built from observed Atlas failure modes and the July 2026 migration,
not generic synthetic requests. It intentionally contains requests that sound
expedient but would violate scientific or deployment integrity.
